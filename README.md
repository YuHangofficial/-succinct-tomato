# 简洁番茄

简洁番茄是一款面向深度工作场景打造的高颜值桌面番茄钟应用。它强调“少而精”的使用体验，把复杂的设置和嘈杂的信息层尽可能藏在后面，把最重要的专注节奏、倒计时状态和当前任务清晰地放在用户眼前。无论是写作、设计、编程、备考，还是需要长时间进入心流的独立工作，简洁番茄都希望像一件安静的桌面器物一样存在，不打扰你，却始终稳稳地托住每一段专注时间。

在视觉上，简洁番茄采用高级极简路线：柔和的莫兰迪色调、克制的玻璃质感、大面积留白、圆润的布局轮廓，以及中心化的超大圆形计时器，共同营造出平静、温柔、可信赖的氛围。它不是传统意义上信息密集型的效率工具，而更像一个专为专注状态设计的“空间界面”。

在功能上，简洁番茄围绕真实的专注流程展开。你可以在专注、短休息、长休息之间自然切换；通过开始、暂停、跳过等操作快速控制当前节奏；把番茄时间绑定到具体任务上，让每一轮专注都有明确目标；在设置中调整专注时长、每日目标、主题、环境音与自动开始逻辑；也可以在统计页里回看累计番茄、专注分钟和连续专注情况。应用还支持中英文切换、本地数据持久化、完成提醒和轻量环境音，让它既适合个人长期使用，也适合被打包成真正可分发的桌面产品。

如果要用一句话概括，简洁番茄不是催促你更快工作的工具，而是一款帮助你更安静、更稳定地进入专注状态的桌面陪伴产品。

## 技术栈

- Next.js 15
- TypeScript
- Tailwind CSS
- Framer Motion
- Zustand
- Tauri 2
- Windows NSIS / MSI 打包

## Recommended setup

```bash
npm install
npm run tauri dev
```

## Build Windows executable

```bash
npm run build
npm run tauri build
```
